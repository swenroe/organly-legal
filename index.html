Politique de confidentialité — Extension Chrome Organly (BETA)

Dernière mise à jour : 2026-01-08

Résumé : l’extension permet de capturer et annoter une capture d’écran, puis de créer une tâche Organly avec la capture en pièce jointe. Elle inclut aussi un module de saisie de temps.

Aucun tracking / publicité : aucune collecte de données à des fins marketing.

Données traitées

  • Captures d’écran : uniquement lorsque l’utilisateur déclenche une capture.
  • Données saisies : titre, description, tags, échéance optionnelle, informations de saisie de temps.
  • Authentification : jeton OAuth (access token) nécessaire pour appeler l’API Organly.

Stockage

  • Stockage local dans le navigateur via chrome.storage.local : jeton OAuth, préférences, état du timer, brouillons.
  • Aucune base de tracking externe n’est utilisée.

Partage et transfert

  • Les données (tâches, captures, entrées de temps) sont envoyées uniquement à Organly et uniquement après validation par l’utilisateur.
  • Aucune vente de données. Aucun partage à des tiers à des fins publicitaires.

Analytics / Tracking

  • Aucun.

Sécurité

  • L’extension utilise OAuth (Authorization Code + PKCE) pour se connecter à Organly.
  • Aucun mot de passe Organly n’est stocké par l’extension.
